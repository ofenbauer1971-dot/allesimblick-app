AllesImBlick – GitHub-Uploadpaket v0.2 Türkis

Enthalten:
- index.html: App-Prototyp mit türkisem Design
- manifest.webmanifest: PWA-App-Metadaten
- sw.js: Offline-App-Shell
- icon.svg: App-Symbol

Wichtig:
Dies ist ein Web-App/PWA-Prototyp, keine fertige native Android-App.
Die Einträge werden lokal im Browser gespeichert. Es gibt noch keine
Hintergrundbenachrichtigungen, Cloud-Synchronisierung oder Verschlüsselung.
Keine vertraulichen Echtdaten in dieser Testversion speichern.
